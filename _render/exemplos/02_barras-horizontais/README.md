# Barras horizontais

Comparação de grandeza entre categorias com nome longo (pessoa, campanha, motivo de perda, canal), lida de cima para baixo. A barra horizontal existe porque rótulo longo girado no eixo é ilegível; aqui o nome fica inteiro e alinhado.

## Modelos

- `01_simples-ordenada`: uma série, do maior para o menor, com rótulo direto de valor e destaque opcional de uma categoria.

## Quando a família serve

- Ranking e comparação entre até uns 15 itens nominais.
- Categoria sem ordem natural, em que a ordem pela grandeza é a leitura.

## Quando procurar outra família

- Série no tempo: use colunas verticais ou linhas.
- Parte de um todo com poucas fatias: use rosca, waffle ou barra 100%.
